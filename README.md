# Smart TaskFlow

A modern, full-stack **Task Management Web App** with **3D animated task cards**, real-time dashboard stats, and a sleek, professional interface. Perfect for productivity and portfolio showcasing.

---

## 🔹 Features

- **Add Tasks:** Title, description, and status (Pending, In-Progress, Completed).  
- **Dynamic Task List:** Tasks appear instantly with a modern 3D card design.  
- **Status Badges:** Color-coded badges for each task status.  
- **Dashboard Stats:** Automatically updates total, in-progress, and completed tasks.  
- **Responsive Design:** Fully responsive for mobile, tablet, and desktop.  
- **Modern UI/UX:** Animated cards, glowing buttons, and gradient backgrounds for a professional look.  

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (modern 3D animations), JavaScript (ES6+)  
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **Other:** Fetch API for frontend-backend communication, UUID for task IDs
